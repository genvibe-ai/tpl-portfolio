# Notice

Ines Valtor is a GenVibe website template: an editorial portfolio for an independent designer.

## Upstream

Based on Maria by Andrei Alba (MIT). Source: https://github.com/xocothemes/maria

What changed: the Astro 7 theme was rebuilt on Vite, React 19, TypeScript, Tailwind CSS 4, motion and
React Router. Maria's editorial idea is kept (large display type with serif italic accents, case-study
pages with role, year and scope, an about page with experience and a résumé link). Everything else is new:
palette, typefaces, layouts, the hero type animation, the grid and index work views, the client wall,
the testimonial carousel, the contact form and the page transitions. No Maria copy, images, logos or icons
are included. Maria's license text is kept in `LICENSE-UPSTREAM`.

## Media

- Images in `public/images`: AI-generated for GenVibe.
- `public/resume.pdf`: a placeholder résumé made for this template.
